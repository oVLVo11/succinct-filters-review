## 0. 符号（本章首次定义）

| 符号 | 含义 |
|---|---|
| `[u]` | 全集 `{0,…,u−1}` |
| `n` | 当前已接受插入次数（insertion-sequence 模型） |
| `ε` | 目标误报率（false positive rate） |
| `δ = u^{−C}` | 整段序列曾报告 failure 的概率上界 |
| `h` | 全局有限独立哈希，把 key 映成长比特串 |
| `i★(n) = ⌈log n⌉` | 插入/查询的操作控制参数（Claim 13 算法句） |
| `ℓ_i` | 第 `i` 阶段写入的前缀长度，式 (2) |
| `D_j` | 容量约 `2^j`、串长上界 `ℓ_j` 的已知容量 prefix-matching 结构 |
| `T_j` | 长度恰为 `j` 的短串真值表，约 `2^j` 比特 |
| `failed` | 底层报告失败后置位；此后定理保证不再适用 |

`log` 以 2 为底（原文脚注）。本章讨论 **filter**；dictionary（Thm 12）仅在底层关系处提及。

## 1. 技术总览：从 filter 到随机哈希前缀

**论文要解决的操作问题**（背景由 A 章详述）：在最终规模未知时，维护近似成员查询，使空间跟随当前 `n`，无漏报，误报 ≤ `ε`，且插入/查询在无 failure 时为 worst-case `O(1)`（高概率意义下整段序列不 failure）。

**本构造的总路线**（论文命题 + 小组概括）：

1. 用全局哈希 `h` 把每个 key `x` 变成足够长的随机比特串，**不再保存**原始 `x`。
2. 第 `n` 次插入只写入 `h(x)` 的前 `ℓ_{i★(n)}` 位。
3. 查询 `y` 化为：**是否存在已存串 `s`，使得 `s` 是 `h(y)` 的前缀**（prefix matching）。
4. 短前缀用真值表 `T`，长前缀用已知容量结构 `D(m,ℓ)`；未知规模则靠「两代 `D/T` 并存 + 后台迁移」拼装（Claim 13 → Lemma 11 → Theorem 10）。

相对 Pagh–Segev–Wieder（PSW）旧构造：本文用真值表处理短串（避免大量复制成长串），用可 in-place、可查询的去均摊迁移替换期望均摊重建，并用更紧的底层冗余支撑 `log log n` 项领先常数为 1（在 `ε=o(1)` 等条件下，见 A 章）。

## 2. 变长前缀、误报预算与 prefix matching 直觉

### 2.1 前缀长度（式 (2)）

**论文命题**（§3.1）：

```text
ℓ_i = i + log(1/ε) + log i + log log log u + 2
```

**小组解释（逐项）**：

| 项 | 作用 |
|---|---|
| `i` | 阶段越大前缀越长；与多阶段规模相关 |
| `log(1/ε)` | 主误报成本，对应经典 filter 每键量级 |
| `log i` | 跨阶段并合时压低第 `i` 阶段贡献 |
| `log log log u`、`+2` | 给底层冗余与并合留余量 |

对非成员，用阶段内至多约 `2^i` 个前缀与碰撞概率 `2^{−ℓ_i}` 做 union bound，可得总和 `< ε`（**精算由 A 给出**；见 `probability-and-space-proof.md` §2）。迁移只改变存放位置，**不改变**该前缀当初按哪一个 `ℓ_i` 计入的预算。

### 2.2 为何查询是前缀匹配

- 插入存的是 `h(x)` 的前缀 `s`。
- 若 `y` 确曾插入，则对应前缀仍在库中（无 failure 时），故 `s` 是 `h(y)` 的前缀 → **无 false negative**。
- 若 `y` 未插入，仅当某个已存前缀碰巧是 `h(y)` 的前缀时误报 → 由 `ℓ_i` 控制。

## 3. 四个活跃结构的职责与生命周期

设当前操作参数 `i = i★(n)`。

| 结构 | 存什么 | 职责 |
|---|---|---|
| `D_i` | 长度 `> i` 的长前缀（通常含新写入） | 当前主写入目标 |
| `D_{i−1}` | 上一控制参数下的长前缀残留 | 迁移源；仍可查 |
| `T_i` | 长度 `= i` 的短串标记 | 接收迁移来的短串 |
| `T_{i−1}` | 更短一层 | 迁出时扩展为两个孩子写入 `T_i` |

**生命周期（小组解释）**：旧层经反复 `decrement` 变空 → `destroy` → 再 `initialize` 更下一层 `T_{i+1},D_{i+1}`。  
**重要区分**：下一层可能已在后台初始化，但 **Lookup 并不查询它们**。「已初始化」≠「查询活跃」。

**口径（未关闭缺口）**：Claim 13 证明段另有半开区间表述 `n∈[2^i,2^{i+1})`；与 `i★=⌈log n⌉` 共用同一字母时有边界冲突（例如 `n=3`）。本章操作描述一律跟 **算法句中的 `i★`**；形式存储归纳标为 **Q1/Q3**，不写成小组已完全证明。

**小边界**：`n=1` 时 `i★=0`，不存在 `D_{−1}/T_{−1}`，查询只触及 `D_0,T_0`；`ℓ_0` 中 `log i` 在实现/分析上需对 `i=0` 做有限特判或从 `i≥1` 起计——原文式 (2) 并合从 `i=1` 写起，初稿此处标 **待与 A 统一口径**。

## 4. 写入、迁移、初始化与销毁

### 4.1 新键写入

第 `n` 次插入：`i←i★(n)`，`s←h(x)` 的前 `ℓ_i` 位。若库中尚无更短前缀覆盖 `s`，则 `insert(D_i,s)`；否则跳过（落入 core set 语义）。  
**新键默认进 `D_i`，不是 `T_i`。**

### 4.2 短串 / 长串迁移去向（Claim 13）

```text
从 T_{i−1} 取出 y  →  写入 T_i 的 y∘0 与 y∘1
从 D_{i−1} 取出 y  →  |y|>i 则进 D_i，否则进 T_i
```

### 4.3 初始化与销毁

`initialize`/`destroy` 对容量 `m` 的结构各需 **O(m)** 次调用才完成（黑盒接口）。算法把它们拆进每次插入后的维护循环，而不是某一次插入里循环到完成。

**对 C 审阅的回应（高优先级）**：不应在单次 `Insert` 中写「while 未就绪 do 线性推进初始化」。正确抽象是：**上一阶段的维护已使当前写入层在需要写入前达到可写状态**（阶段就绪不变式，意图）；单次插入只做常数轮推进。若实现上偶发未就绪，应视为进度配平缺口（与字面 10 的 Q3 同类），而不是引入隐藏的 `Θ(m)` 工作。

## 5. 查询为何只访问常数个结构

**论文命题**（Claim 13 末）：`i←⌈log n⌉`，同时查询

```text
D_{i−1}, D_i, T_{i−1}, T_i
```

（缺失的负下标层视为空。）任一返回 YES 则 YES，否则 NO。

**小组解释**：未知规模若简单保留全部历史 filter，查询可能扫 `Θ(log n)` 层；本文始终只保留并检查常数个相邻层，从而 worst-case `O(1)`（在底层单次 query 为 O(1) 且 `¬failed` 时）。

## 6. 插入的去均摊化

**论文命题**：每次插入后执行维护过程 **10** 次（Claim 13）。

抽象上，一轮维护即一次 `MigrateOneStep(i)`：尝试迁 `T`/`D`、推进 destroy、推进 initialize 下一层（见 `pseudocode.md`）。

| 层次 | 表述 |
|---|---|
| 控制流 | 单次 Insert = 1 次 `D.insert` + 10 轮维护 = **O(1)** 次底层调用 |
| 渐近配平 | 阶段长度 `Θ(2^i)` 与 init/destroy/decrement 总需求同阶，故**存在**足够大的常数轮数 |
| 字面 10 | **论文采用 10**；黑盒仅给 `O(m)`，**小组未证明「恰好 10 必然够」**（Q3） |

§5 内部 data block 满块后的重组同样拆到后续插入的常数步中；上层时间证明依赖「底层原语已是 O(1)」。

## 7. 无 false negative：写入、迁移与查询覆盖

**论文命题**：无 failure 时，每个 query 正确回答；成员必 YES（Thm 10；Claim 13）。

**小组解释（三种状态）**：

1. **插入刚完成**：新前缀在 `D_i`（或已被更短前缀覆盖）→ 对 `h(x)` 的查询命中。  
2. **迁移中**：串要么仍在旧层，要么已写入新层；Lookup 同时查旧层与新层。  
3. **迁移后**：旧层在 Empty 后才 destroy；串已在新层。

**缺口**：把上述意图写成对所有 `n` 的形式归纳时，受阶段下标冲突阻塞；控制流层论证视为已核实，完整归纳 **不关闭**。

## 8. 误报、failure、时间与空间的依赖链

```text
式 (2) + 有限独立哈希 ──► FP ≤ ε          （A 主核精算）
写入+迁移+四结构查询 ──► 无 FN            （B；条件 ¬failed）
四次 query / 常数轮维护 ──► 时间 O(1)     （B；底层 O(1)）
Lemma 11 + ℓ_i 代入    ──► 空间主体       （A；B 确认层数常数）
§5 坏事件 → 每层 u^{-2C} → (log u) 并合 ──► failure ≤ δ  （A）
```

**必须区分**：

- **ε（false positive）**：无 failure 时，非成员被误判为成员的概率；  
- **δ（failure）**：结构宣布无法维持保证的概率。  

二者不可加总成“总错误率”。公开 API 的正确性与时间保证均以 **conditioned on no failure** 为条件。引言关于“失败后可线性重建使期望仍为常数”的脚注**不是** Claim 13 的公开 rebuild 接口。

共同六行表见 `notes/proof-table.md`。

## 9. 底层 `D(m,ℓ)`：接口、data block 与抽象边界

### 9.1 黑盒接口（Claim 13 之前）

容量 `m`，串长上界 `ℓ≥log m`。支持 `initialize`/`destroy`（各 O(m) 次调用完成）、`insert`、`query`（是否存在前缀）、`decrement`（取出一串；空调用 ≤ m）。  
空间接口约 `q(ℓ−log m+2 log log log u)+O(m)`（插入 `q` 个长串后）。对规定随机分布，单实例 failure ≤ `u^{−2C}`。

**“长串上的 membership 为何能做 prefix matching”**：在接口层，`query(D,x)` 直接回答是否存在已存串为 `x` 的前缀；Claim 13 写入 `D_i` 的串来自 core set，使分布假设成立。

### 9.2 Data block 角色（§5，综述级）

`D` 内部：main table（按 `st(x)` 分桶）→ subtable → adaptive prefixes + navigator → data blocks。  
最新块动态插入；满块后台重组为静态紧凑编码，以把每键冗余压到约 `O(log log log u)` 量级，避免破坏 filter 的 `log log n` 领先常数。

**抽象边界**：本章 Review **不假装**已完成 §5 每一位级证明；空间低阶项与 failure 式 (3)(4)(5) 以 A 的核查为准，未闭合细节标 Q2/Q3。

## 10. 贯穿示例：插入—迁移—查询（教学）

下列为 **教学示例**，示意前缀人为指定，**不代替**概率、空间或配平证明。

设连续插入 `x1…x8`，`i★(n)` 为 `0,1,2,2,3,3,3,3`。

| n | 新键进入 | 查询活跃 | 维护在推进 |
|---|---|---|---|
| 1 | `D0` | `D0,T0` | （无 −1 层） |
| 2 | `D1` | `D0,D1,T0,T1` | 迁 `T0/D0`；init `T2/D2` |
| 3–4 | `D2` | `D1,D2,T1,T2` | 迁 `T1/D1`；init `T3/D3` |
| 5–8 | `D3` | `D2,D3,T2,T3` | 迁 `T2/D2`；init `T4/D4` |

要点：新键进 `D`；`T` 主要收迁移短串；查询层数恒为常数；10 轮是后台进度而非一次搬空。

更细表见 `construction-notes.md` §6、`figures/growth-process.md`。
