## 1. 从成员查询到 unknown-size filter

许多系统都要反复回答“某个 key 是否已经出现”：缓存在访问慢速存储前先过滤不可能命中的请求，存储系统避免对明显不存在的对象做昂贵查找，数据库在执行连接或去重前筛掉大量负例。若使用 exact dictionary，查询必须完全准确；若使用 approximate membership filter，则允许将少量非成员错认为成员，以换取更小的空间。

经典 filter 往往在初始化时就知道或假定一个容量上界 `N`。如果实际集合一直只有 `n≪N` 个元素，按 `N` 预留的比特就被长期浪费；如果 `N` 估小，结构又必须扩容。本文研究的正是后一种更苛刻的在线目标：不事先知道紧的最终容量，却要让空间在每个中间时刻都跟随当前规模，并同时保持低误报和常数操作时间。

## 2. 模型与符号

全文以 2 为底取对数。全集记为 `[u]={0,1,…,u-1}`，当前逻辑集合为 `S⊆[u]`，当前规模为 `n`。LYY 的构造按第几次插入划分阶段；本 Review 默认讨论互异 key 的 insertion-only 序列，不把重复插入的工程去重语义当成已证结论。

- `insert(x)` 将 `x∈[u]` 加入逻辑集合。
- `lookup(x)` 回答 `x` 是否属于集合。
- exact dictionary 对成员和非成员都必须精确。
- filter 对已插入成员不允许 false negative（漏报）；对非成员允许 false positive（误报），其概率上界记为 `0<ε<1`。

“Unknown size”不是说全集大小 `u` 未知，也不是说数据结构不知道自己已处理了多少次插入；它表示初始化时没有给出最终集合大小或紧的容量上界 `N`。目标是让输入相关空间依赖当前 `n`，而不是长期依赖一个过度保守的 `N`。

## 3. 为什么 filter 的扩容比 exact dictionary 难

Exact dictionary 保留了足够恢复每个旧 key 的信息，因此表满后可以枚举所有 key，建立更大的表并逐一重插入。Filter 的空间优势恰恰来自丢弃了恢复原 key 所需的大量信息：它可能只保存指纹、位图效应或哈希前缀。当新阶段需要更长指纹时，旧状态未必含有那些额外比特，因而不能简单执行“枚举旧 key 再重建”。

PSW 的早期构造使用附加哈希比特和前缀展开解决了部分信息丢失，但要同时得到当前规模下的 succinct 空间和最坏常数时间，还需要 LYY 的变长前缀、prefix matching、短串 truth table、长串已知容量结构以及两代并存迁移机制。

## 4. 主要结果：非正式展示与正式定理

### 4.1 Theorem 10：完整正式保证

设 `δ=u^{-C}`，其中 `C>1` 是任意常数；word-RAM 字长 `w=Θ(log u)`。对任意 `0<ε<1`，Theorem 10 给出 unknown-size approximate membership 结构，满足：

1. 当 `n=ω(log u)` 且 `n<u` 时，输入相关空间为
   `n(log(1/ε)+log log n+O(log log log u))` 位；另有与输入无关的 `u^c` 位预计算内容，其中 `0<c<1` 可取任意小的常数。
2. 每次插入和 membership query 均为 worst-case `O(1)`。
3. 对任意插入序列，整个过程中曾报告 failure 的概率至多为 `δ`；概率取自预计算随机比特。
4. 在没有 failure 的条件下，已插入成员不会漏报，非成员查询的误报率至多为 `ε`。

这里 `ε` 和 `δ` 描述两种不同事件：`ε` 是 no-failure 执行中单个非成员查询的允许误报；`δ` 是整段插入序列上结构曾进入坏事件的概率上界。它们不能相加成一个模糊的“总错误率”。

### 4.2 Theorem 1：在更强条件下展示 succinct 主项

非正式 Theorem 1 在 `n>u^{0.001}` 时把空间写成

```text
(1+o(1)) n(log(1/ε)+log log n).
```

这不是 Theorem 10 的字面前提，而是一个用来吸收低阶项的展示条件。因为 `n>u^{0.001}` 时 `log log log u=o(log log n)`；又可选固定 `c<0.001`，使 `u^c=o(n)`。因此 Theorem 10 中的每元素低阶项和输入无关预计算空间都可被吸收到 `(1+o(1))` 中。

## 5. 上界中 `log log n` 从何而来

第 `i` 个翻倍阶段最多包含约 `2^i` 个哈希前缀。LYY 对该阶段新插入 key 保存长度

```text
ℓ_i = i + log(1/ε) + log i + log log log u + 2.        (2)
```

对固定非成员查询，它与一个长 `ℓ_i` 前缀碰撞的概率是 `2^{-ℓ_i}`。对阶段内元素和所有阶段使用 union bound：

```text
Σ_{i=1}^{⌈log n⌉} 2^i 2^{-ℓ_i}
= Σ_i ε/(4 i log log u)
< ε.
```

`ℓ_i` 中的 `log i` 让各阶段误报预算可求和；又因为当前阶段 `i≈log n`，这项在每个 key 上表现为 `log log n`。迁移只改变前缀的存放位置，不会为同一前缀重新产生一份独立误报预算。

但这个求和只解释了 LYY 构造为什么使用 `log log n` 位，并未排除完全不用分阶段方法的其他结构。要说明这个代价是理论上普遍不可避免的，必须使用 PSW 的独立信息论下界。

## 6. PSW 下界：从近似成员查询到压缩矛盾

### 6.1 参数化定理

PSW Theorem 3.1 设 `n≤εu` 且 `n` 足够大，`1/√n≤α<1`，`γ≥2` 为整数。如果对每个 `αn<m<n` 的插入序列，数据结构在规模 `m` 时都只使用至多 `βm` 位，那么

```text
β ≥ (1-1/γ)
    (log(1/ε) + (1-9ε)log log_γ(1/α) - Θ(1)).
```

定理的强点在于，它不限制查询或插入时间，还允许结构免费访问只读随机比特。因此下界限制的是“状态中必须含有多少信息”，而不是某个实现的时间浪费。

### 6.2 六步证明骨架

1. **固定随机性。** 对随机串 `r` 和插入序列 `S`，记 `Ŝ_r` 为结构回答 YES 的全部 universe 元素。无漏报保证 `S⊆Ŝ_r`，误报率保证 `E_r[|Ŝ_r|/u]≤ε+n/u≤2ε`。用 Markov 不等式和平均论证，可固定一个 `r*`，使至少 `u^n/2` 条序列的正回答集合测度不超过 `4ε`。
2. **几何分块。** 把序列分成长度为 `γ^i` 的连续块 `C_i`，前 `i` 块组成前缀 `S_i`。由于没有漏报，正回答集合随插入单调扩大。
3. **找到正回答集合增长很小的块。** 在 `αn` 到 `n` 的若干几何尺度中，总增长不超过 `4ε`。抽屉原理保证存在一块，其新增 YES 集合测度至多为 `4ε/(log_γ(1/α)-2)`。
4. **控制块内旧误报。** 在插入 `C_i` 之前就已经被回答 YES 的块内元素数记为 `k`。Chernoff 界与 union bound 保证对至少 `u^n/3` 条序列有 `k≤9ε|C_i|`。
5. **用中间状态编码。** 显式写出块外元素，再写出结构处理 `C_i` 后的中间状态。因为随机性已固定，块前后的 YES 集合都由这些信息确定。块内的大多数新元素可相对于很小的集合差编码，而少量旧误报元素相对于旧 YES 集合编码。
6. **不可压缩性导出矛盾。** 至少 `u^n/3` 条不同序列需要 `n log u-O(1)` 位才能无歧义编码。如果每个中间状态都太小，上述编码就会比计数下界更短，产生矛盾；因而至少有一个中间时刻必须支付额外双重对数信息。

### 6.3 从参数化定理到 `n log log n`

PSW 取 `α=1/√n` 和 `γ=2^{(log n)^η}`（`0<η<1`），从 Theorem 3.1 得到 Theorem 1.1 字面陈述的

```text
(1-o(1))n log(1/ε) + Ω(n log log n).
```

若让 `γ` 随 `n` 更缓慢地增长，则可在 `1/γ=o(1)` 的同时使 `log log_γ(1/α)=log log n-o(log log n)`。结合 `(1-9ε)`，LYY 将其概括为

```text
(1-o(1))n(log(1/ε)+(1-O(ε))log log n).
```

因此，“PSW Theorem 1.1 字面就给出了精确系数 1”并不准确；精细领先项来自 Theorem 3.1 的参数化形式。当 `ε=o(1)` 时，下界中 `log log n` 的系数趋近 1，与 LYY 上界的对应领先项对齐。对固定常数 `ε`，仅凭 `(1-O(ε))` 不能声称系数严格等于 1。

## 7. 空间、failure 和时间保证如何衔接

Lemma 11 在 `n` 次插入后给出 prefix-matching 空间

```text
n(ℓ_{⌈log n⌉}-log n+O(log log log u))+u^c.
```

代入式 (2)，使用 `⌈log n⌉-log n=O(1)` 和 `log⌈log n⌉=log log n+O(1)`，得到 Theorem 10 的主体空间。Claim 13 在查询时只访问相邻两代 `D/T` 结构，而不扫描 `Θ(log n)` 个历史 filter；但位级迁移峰值的领先常数仍由 Lemma 11 的正式命题承担，不能仅由“查四个结构”推出。

对 failure，已知容量结构 `D(m,ℓ)` 中的主表过载、fingerprint collection 失败和 data block 相关坏事件经式 (3)–(5) 并合为单层至多 `u^{-2C}`。对至多 `log u` 个容量层再用一次 union bound：

```text
(⌈log u⌉)u^{-2C} ≤ u^{-C}=δ
```

对足够大的 `u` 和 `C>1` 成立。时间方面，查询只做常数次底层 query，每次插入把迁移、销毁和下一层初始化拆成常数轮后台工作。原文 Claim 13 取每次 10 轮；本 Review 保留字面常数的黑盒常数配平问题，但不影响“存在足够大常数轮数”的渐近直觉。

## 8. 这项结果为什么重要

本文的非凡之处不在于单独发明了哈希前缀或去均摊，而在于把多个彼此制约的目标同时对齐：

- **信息论层面**：unknown-size 必须支付的 `log log n` 额外成本被显式体现；在 `ε=o(1)` 等条件下，上界与 PSW 参数化下界的对应领先项对齐。
- **在线时间层面**：只有信息论上小的空间还不够；本文还将查询限制为常数个活跃结构，并将迁移去均摊到每次插入。
- **当前规模层面**：结构不靠一个过度保守的最终容量占用主体空间，而在插入过程中跟随当前 `n`。
- **证明层面**：误报、无漏报、结构 failure、最坏时间和位级空间不能各自孤立处理；本文通过全局哈希、核心前缀集、`D/T` 生命周期和底层已知容量接口将这些保证连成一条依赖链。

因此，更准确的评价是：LYY 在 insertion-only unknown-size word-RAM 模型下实现了一组很强的联合保证；这不等于它在删除、工程吞吐、缓存局部性或所有对手模型上都全面优于其他 filter。

## 9. 条件与限制汇总

1. Theorem 10 的正式规模范围是 `n=ω(log u)` 且 `n<u`；Theorem 1 的 `n>u^{0.001}` 是化简展示的更强条件。
2. `u^c` 位预计算内容与输入无关，但仍是总空间的一部分；不能在正式定理中删去。
3. “`log log n` 领先常数对齐”需要 `ε=o(1)` 等参数条件；对固定 `ε`不作系数严格等于 1 的扩张。
4. 无漏报、误报率和 worst-case `O(1)` 的对外解释必须保留 no-failure 条件；整段序列曾 failure 的概率由 `δ=u^{-C}` 单独控制。
5. 主定理是 insertion-only，不支持用户删除；“无紧最终容量”也不表示宇宙无限。
6. 本 Review 不将原文概率保证无条件扩张到自适应查询对手。
7. Claim 13 中阶段下标的形式归纳、每插入 10 轮的隐含常数配平和迁移临时位级峰值仍是本组的 Q1/Q3 核查项，不由教学示例或渐近直觉替代证明。
